# EditCore

**EditCore** — веб-редактор изображений, иллюстраций и игровых спрайтов на **Next.js** и **React** (`FullPhotoShopEditor`, JSX). Проект создан для работы прямо в браузере: без сложной установки, с поддержкой слоёв, истории изменений, трансформаций, фильтров, точного масштабирования и перемещения холста инструментом **«✋ Рука»**.

## Возможности редактора

Интерфейс редактора разделён на три основные зоны: **левую панель инструментов**, **центральную рабочую область с верхней панелью управления** и **правую панель слоёв и фильтров**.

### Левая панель: инструменты рисования и редактирования

* **🖌️ Кисть (`brush`)** — свободное рисование выбранным цветом (`color`) и толщиной (`size` от `1` до `50` px) со скруглёнными краями (`lineCap = 'round'`, `lineJoin = 'round'`).
* **🪣 Заливка (`fill`)** — заливка замкнутой области выбранным цветом через алгоритм заливки (`floodFill`) с проверкой схожести каналов RGBA (допуск ±15 единиц по каждому каналу), что позволяет аккуратно заливать области без артефактов на краях.
* **🧹 Ластик (`eraser`)** — стирание с регулируемым размером (`eraserSize` от `1` до `100` px):
  * на нижнем слое при включённой опции **«Белый фон (слой 1)»** стирает до белого цвета (`#ffffff`);
  * на остальных слоях и при выключенном белом фоне стирает до прозрачности (`destination-out`).
* **💉 Пипетка (`eyedropper`)** — считывает цвет пикселя в точке клика с композитного холста (`displayCanvasRef`), переводит его в формат `HEX` и автоматически возвращает активный инструмент на **Кисть**.
* **⬜ Прямоугольник (`rect`)** — построение прямоугольника от начальной точки нажатия до текущей позиции курсора с предпросмотром поверх снимка слоя (`snapshot`). Поддерживает контур и сплошную заливку (чекбокс **«Заливать фигуру»**).
* **⭕ Круг (`circle`)** — построение окружности по радиусу (`Math.hypot`) от точки нажатия с предпросмотром и поддержкой контура или заливки.
* **🔤 Текст (`text`)** — вставка текста из поля ввода по клику на холсте; размер шрифта зависит от параметра `size` (`Math.max(10, size * 4)px`).

## Навигация, масштаб и инструмент «Рука»

При работе с крупным масштабом или мелкими спрайтами важно удобно сдвигать холст и не оставлять случайных штрихов.

* **Кнопка «✋ Рука» (`handMode`)** в верхней панели (`topBar`) включает режим панорамирования холста в рабочей области (`canvasArea`):
  * при активном режиме «Рука» клик и перетаскивание двигают холст (`pan`) вместо рисования;
  * также панорамирование работает при удержании **средней кнопки мыши** (`e.button === 1`);
  * курсор меняется на `grab` в покое и `grabbing` во время перетаскивания.
* **Сброс позиции и масштаба:**
  * **Двойной клик** по кнопке **«✋ Рука»** — сбрасывает смещение холста (`pan` → `{ x: 0, y: 0 }`);
  * **Клик по индикатору масштаба (`{zoom}%`)** в верхней панели — возвращает масштаб к `75%` и сбрасывает смещение холста в `{ x: 0, y: 0 }`.
* **Масштабирование (`zoom`):** ступенчатое изменение масштаба кнопками `−` и `+` по шкале уровней `25%`, `50%`, `75%`, `100%`, `150%`, `200%`, `300%`, `400%`, `600%`, `800%`, `1200%`, `1600%` (по умолчанию `75%`). При увеличении выше `100%` подключается класс `.pixelated` для чёткого отображения пикселей.

## Управление холстом, сеткой и слоями

### Холст и сетка
* **Размер холста:** настраивается вручную по ширине и высоте в диапазоне от `16` до `2048` px (`MIN_SIZE` / `MAX_SIZE`) с кнопкой **«📐 Изменить размер»** или быстрыми пресетами **`32×32`**, **`64×64`**, **`512×512`**.
* **Белый фон (слой 1):** переключатель позволяет добавить или сохранить белый фон на базовом слое.
* **Сетка:** при включении опции **«Показать сетку»** поверх холста отображается сетка с шагом **`8 × 8`**, **`16 × 16`**, **`32 × 32`** или **`64 × 64` px**, которая автоматически масштабируется вместе с зумом.
* **Открытие изображения:** кнопка **«📂 Открыть фото»** загружает выбранный файл изображения, подстраивает размер холста под размеры картинки (в пределах `16–2048` px) и отрисовывает её на активном слое.

### Слои (правая панель)
* **+ Новый** — создаёт новый прозрачный слой поверх текущих и делает его активным.
* **Выбор активного слоя** — клик по слою выбирает его для рисования, заливки, очистки или применения фильтров.
* **Видимость (`👁️` / `🚫`)** — включает или скрывает слой на итоговом холсте.
* **Порядок слоёв (`▲` / `▼`)** — перемещает слой выше или ниже в стеке.
* **Удаление слоя (`✕`)** — удаляет выбранный слой (нельзя удалить последний оставшийся слой).
* **🗑️ Очистить слой** — очищает содержимое текущего активного слоя.

## Фильтры, трансформации, история и сохранение

### Трансформации
* **🔄 Повернуть 90°** — поворачивает все слои и меняет местами ширину и высоту холста.
* **↔️ Отразить** — зеркально отражает содержимое всех слоёв по горизонтали.

### Фильтры
В правой панели доступны ползунки предпросмотра в реальном времени:
* **Яркость** (`0–200%`, по умолчанию `100%`);
* **Контраст** (`0–200%`, по умолчанию `100%`);
* **Ч/Б (`grayscale`)** (`0–100%`, по умолчанию `0%`);
* **Сепия (`sepia`)** (`0–100%`, по умолчанию `0%`).

Фильтры можно **запечь в активный слой** кнопкой **«Применить фильтры к слою»**, **сбросить** к исходным значениям кнопкой **«Сбросить фильтры»** или учесть при экспорте.

### История действий (`Undo` / `Redo`) и экспорт
* **История:** каждое изменение слоёв, размеров, трансформаций или заливки сохраняется в стек истории (`historyState`), позволяя откатывать и повторять шаги.
* **💾 Сохранить PNG:** собирает все видимые слои на временном холсте с учётом активных фильтров и скачивает файл `character-sprite.png`.

## Горячие клавиши и жесты

| Действие | Горячая клавиша / Жест |
| :--- | :--- |
| Отменить действие (`Undo`) | `Ctrl + Z` / `Cmd + Z` |
| Повторить действие (`Redo`) | `Ctrl + Shift + Z` / `Cmd + Shift + Z` или `Ctrl + Y` |
| Перетащить холст («Рука») | Перетаскивание в `canvasArea` при активной «✋ Рука» или зажатая средняя кнопка мыши |
| Сбросить смещение холста | Двойной клик по кнопке **«✋ Рука»** |
| Сбросить масштаб (`75%`) и позицию | Клик по индикатору масштаба (`{zoom}%`) |

## Структура проекта и стили

* Компонент редактора реализован в клиентском модуле Next.js (`'use client'`) и подключает стили из CSS-модуля `./editor.module.css`.
* Для корректного отображения курсоров инструмента **«Рука»** добавьте в `editor.module.css` следующие классы:

```css
.cursorGrab {
  cursor: grab;
}

.cursorGrabbing {
  cursor: grabbing;
}
